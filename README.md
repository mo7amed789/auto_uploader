# أداة الرفع التلقائي لإنستغرام ريلز (Instagram Reels Auto-Uploader)

أداة سطح مكتب بواجهة رسومية بسيطة وسهلة الاستخدام لرفع فيديوهات يوتيوب شورتس (YouTube Shorts) المحفوظة على جهاز الكمبيوتر إلى حسابك في إنستغرام (Instagram Reels) تلقائياً، مع جدولة ذكية وفواصل زمنية لحماية الحساب.

---

## 🌟 المميزات الرئيسية

1. **واجهة رسومية تفاعلية (Desktop GUI)**: تمكنك من اختيار الفيديوهات الفردية أو استيراد مجلد كامل بنقرة زر واحدة.
2. **رفع مباشر كـ Reels**: ترفع الفيديوهات بصيغة Reels الرسمية بكامل الجودة والأبعاد.
3. **حفظ جلسة الدخول (Session Persistence)**: يحفظ البرنامج جلسة تسجيل الدخول محلياً (`session.json`) حتى لا تحتاج لإدخال كلمة المرور في كل مرة ولا تثير شكوك خوارزميات الأمان في إنستغرام.
4. **دعم المصادقة الثنائية (2FA)**: إذا كان حسابك مفعّلاً به التحقق بخطوتين، ستظهر لك نافذة منبثقة لإدخال الكود بكل سهولة.
5. **منع التكرار (Duplicate Prevention)**: يتم حفظ الفيديوهات التي تم رفعها بنجاح في ملف `uploaded_history.json` لمنع إعادة رفع نفس الفيديو بالخطأ.
6. **فواصل زمنية آمنة (Anti-Ban Delay)**: إمكانية تحديد فاصل زمني بالدقائق بين كل فيديو وآخر (يُنصح بـ 15 إلى 30 دقيقة على الأقل) لتجنب حظر النشر المؤقت.
7. **تخصيص الكابشن والهاشتاجات**: يمكنك استخدام القالب التلقائي مع المتغير `{filename}` لوضع اسم الفيديو كعنوان تلقائي متبوعاً بالهاشتاجات التي تختارها.
8. **دعم البروكسي (Proxy)**: إمكانية تشغيل الأداة عبر بروكسي مخصص لمزيد من الأمان.

## 🚀 طريقة التشغيل السريعة

### الطريقة الأولى: التشغيل بنقرة زر واحدة (Windows)
فقط قم بالضغط مرتين على ملف:
```
run.bat
```

### الطريقة الثانية: عبر سطر الأوامر (Terminal / PowerShell)
1. افتح نافذة الأوامر في مجلد البرنامج:
   ```powershell
   cd "C:\Users\RDP\.gemini\antigravity\scratch\instagram_auto_uploader"
   ```
2. شغّل البرنامج:
   ```powershell
   python main.py
   ```

## ⚙️ وضع سطر الأوامر المباشر (CLI Mode)

إذا كنت تفضل تشغيل الأداة في الخلفية دون واجهة رسومية:
```powershell
python main.py --cli --username "your_instagram_user" --password "your_password" --folder "C:\Path\To\Shorts" --delay 15
```

## 🛡️ نصائح هامة لحماية حسابك من التقييد أو الحظر

> [!IMPORTANT]
> خوارزميات إنستغرام تراقب معدل النشر السريع وتعتبره سلوكاً آلياً (Spam). لحماية حسابك:
> 1. **الفاصل الزمني**: لا تضع فاصلاً زمنياً أقل من **15 دقيقة** بين كل فيديو وآخر. الأفضل هو 20-30 دقيقة.
> 2. **الحد اليومي**: لا ترفع أكثر من **10 إلى 15 ريل في اليوم الواحد** لحساب جديد أو متوسط.
> 3. **تأكيد تسجيل الدخول**: في أول مرة تسجل فيها الدخول عبر الأداة، قد يرسل لك إنستغرام إشعاراً على هاتفك يسألك: *"هل أنت من قام بتسجيل الدخول؟"* اضغط على **"نعم، هذا أنا" (This was me)**.
